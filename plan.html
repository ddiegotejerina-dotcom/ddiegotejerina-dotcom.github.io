EQUILIBRIO

A real-time geopolitical strategy game for the browser. Pick a power (USA, China, Russia, Brazil or Argentina) and compete for influence on an isometric map of the real world, while trying to keep the world from sliding into nuclear winter.

Goal and scope

What it has to achieve

A strategy game built for long sessions on a computer, in the spirit of Twilight Struggle or Hearts of Iron but simpler. It has to be fun with any power and easy to understand without a manual.

In scope

  • Navigable isometric map with real geography (Natural Earth)
  • Real-time clock with pause and three speeds
  • Military, hybrid, economic, diplomatic and domestic actions
  • AI rivals, treaties, military pacts and events with decisions
  • Economy, construction, country-specific victories and defeats
  • Save games, code-generated sound, English version

Out of scope (for now)

  • Multiplayer and servers
  • Tactical combat with troop movement
  • Mobile version
  • Paid audio or art assets (everything is CC0 or generated in code)
  • User accounts or cloud data
How we work

The cycle of each stage

The project moves forward in short stages. None starts until the previous one works and is approved, and every design change is written into the spec first.

1

Specify

The idea goes into the spec (SPEC.md) with rules, numbers and acceptance criteria.

2

Plan

A detailed stage plan: what changes, which files it touches and how it will be tested. Approved before any code is written.

3

Build and test

Coding, in-browser testing, multi-year simulations and performance measurement.

4

Playtest and approve

A real game with different powers. Findings go back into the spec as tweaks or new stages.

Decision log

Key decisions

Kickoff

No frameworks, nothing to install

Plain HTML and JavaScript: the game opens with a double click. Simpler to maintain and to learn from.

Kickoff

The spec leads

Every design change is written into SPEC.md first. The code follows the document, not the other way around.

Nov 12

USA victory threshold based on data

Changed from "30% more than China" to "double": the USA starts 50% ahead, so 30% would have been an automatic win.

Nov 12

Large stages split in two

Winning and losing were built and tested separately (6b-1 and 6b-2) so each part could be approved through play.

Nov 13

Living world before more actions

After a playtest with Brazil, the game felt "action-driven". More actions would reinforce that, so lasting situations come first.

Quality

Every stage

  • Each rule tested by forcing the case (debt, crisis, victory)
  • Six-year AI-only simulation to check the world neither freezes nor falls apart
  • Save and load, including saves from earlier versions
  • Screens 1280 px wide and up
